# Java Programs

This repository contains simple Java practice programs.

## Programs

### 1. Hello World
File: `first.java`

Output:
```text
Hello, World!
```

### 2. Star Pattern 1
File: `star1.java`

Output:
```text
*
**
***
****
```

### 3. Star Pattern 2
File: `star2.java`

Output:
```text
****
***
**
*
```

## How to run

```bash
javac *.java
java first
java star1
java star2
```
